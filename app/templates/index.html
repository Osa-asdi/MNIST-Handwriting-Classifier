REST API Reference

×

This Flask application exposes production-ready REST endpoints for seamless MLOps integration.

POST /api/predict/canvas

Predicts digit from a Base64 encoded image string.

curl -X POST http://localhost:5000/api/predict/canvas \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgo..."}'
POST /api/predict/upload

Uploads a digit image file directly via multipart form data.

curl -X POST http://localhost:5000/api/predict/upload \
  -F "file=@digit.png"
POST /api/predict/url

Fetches and classifies an image directly from an HTTP/HTTPS URL.

curl -X POST http://localhost:5000/api/predict/url \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/digit.png"}'
POST /api/predict/features

Direct 784 normalized pixel vector prediction.

curl -X POST http://localhost:5000/api/predict/features \
  -H "Content-Type: application/json" \
  -d '{"features": [0.0, 0.0, 0.52, ... 784 items]}'
GET /api/health

Health check for orchestration (Docker / Kubernetes / monitoring).

curl http://localhost:5000/api/health
